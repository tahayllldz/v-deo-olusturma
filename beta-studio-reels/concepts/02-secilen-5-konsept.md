**Birbirinden farklılık kontrolü**

- Zemin: krem / kobalt / gece / krem-bölünmüş / siyah→krem → feed'de yan yana dizildiğinde hiçbiri birbirini tekrar etmiyor.
- Ana nesne: tarayıcı / profil + huni / sohbet ekranı / ikiye bölünmüş site / sadece tipografi.
- Hareket imzası: imleç hikâyesi / sayaç + akan noktalar / mesaj yağmuru / sürüklenen ayırıcı / tam ekran kelime çarpması.
- Ortak DNA (logo görünmeden tanınma): kobalt imleç-çizgisi ("Beta caret"), sol üst seri etiketi + bölüm çizgileri, Bricolage Grotesque + Instrument Serif italik vurgu + JetBrains Mono etiket üçlüsü, kırmızı kalem = problem / kobalt = çözüm dili.
