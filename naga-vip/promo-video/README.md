# NAGA VIP — Remotion project

Promo video, product mockups and the owner presentation are all rendered from this
Remotion project (one shared design system). See **[../README.md](../README.md)** for
the full workflow (Windows commands, ElevenLabs voiceover, exports).

```powershell
npm install
npm run studio      # live preview: Promo-Landscape, Promo-Portrait, Scenes, Slides, Mockups
npm run export      # mockups + slides + PDF/PPTX + both MP4s
```
